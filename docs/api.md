# AgentFi — REST API Documentation

The AgentFi API is built with FastAPI and runs on port 8000. It provides 37 endpoints covering authentication, agent discovery, risk profiles, subscriptions, portfolios, signals, trades, and deterministic demo scenarios.

---

## 🔐 Auth & Onboarding

### `POST /auth/request-otp`
Sends an OTP verification code to a user's WhatsApp number.
- **Request Body:**
  ```json
  { "whatsapp_number": "+14155238886" }
  ```
- **Response:**
  ```json
  { "success": true, "message": "Verification code dispatched via WhatsApp" }
  ```

### `POST /auth/verify-otp`
Verifies OTP code and provisions an embedded Privy smart account if new.
- **Request Body:**
  ```json
  { "whatsapp_number": "+14155238886", "code": "491823" }
  ```
- **Response:**
  ```json
  {
    "access_token": "eyJhbGciOi...",
    "token_type": "bearer",
    "user": {
      "id": "uuid",
      "wallet_address": "0x82A...41b0",
      "risk_level": "MEDIUM"
    }
  }
  ```

## 🤖 Agent Marketplace

### `GET /agents/`
Lists verified agents with filters for category, price, and minimum rating.
- **Query Params:** `category`, `max_price`, `risk_level`, `limit`, `offset`

### `GET /agents/{agent_id}`
Returns complete agent details, ENS identity, capabilities, and review stats.

### `POST /agents/`
Publishes a new agent (developer endpoint) with machine-readable manifest and ENS subname binding.

### `POST /agents/{agent_id}/review`
Submits an onchain review with anti-self-review protection and attestation hash.

---

## 📊 Signals & Multi-Agent Swarm

### `GET /signals/`
Returns latest signals generated by `NewsScout`, `MarketMind`, `WhaleWatcher Pro`, and `SentimentAgent`.

### `POST /trades/analyze`
Coordinates the 5-agent swarm on a target asset and returns composite alpha score with explainability.
- **Request Body:**
  ```json
  { "asset": "ETH", "budget_usd": 20.0 }
  ```

## 🛡️ Risk & Permissions

### `POST /permissions/`
Creates a scoped session key permission object:
```json
{
  "agent_id": "whalewatcher-pro",
  "max_transaction": 20.0,
  "daily_limit": 50.0,
  "allowed_actions": ["SWAP", "ANALYZE"],
  "blocked_actions": ["WITHDRAW"],
  "expires_in_hours": 24
}
```
